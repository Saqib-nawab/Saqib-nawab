# 💫 About Me:
Full Stack Developer with 3+ years of experience designing, building, and shipping production web applications using Next.js, React, Angular, Node.js, and Python (Django, FastAPI, Flask) across the MERN, MEAN, and PERN stacks. I specialize in AI/LLM-powered products and large-scale data engineering — scraping and structuring 20 TB+ of video and millions of documents from clinical conferences. I've delivered end-to-end platforms like Curexity (AI-powered clinical trial discovery), MEENAS (AI-driven international trade platform), and MacMap (global trade statistics explorer), with a strong background in PostgreSQL, MongoDB, Elasticsearch, Docker, and secure, scalable API architecture. I thrive in agile environments with collaborative, cross-functional teams.
